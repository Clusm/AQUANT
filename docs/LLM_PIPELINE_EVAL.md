# LLM 管线评估(v0.4.0 内部记录)

数据: `scripts/eval_recommendations.py` 自动扫描本地 44 条历史信号(推荐 JSON + full_states_log 去重)。
行情: `daily_main_board.parquet` + `index_000001.parquet`。
口径: 信号日期下一交易日收盘买入,前向 3/5/10 个交易日收益,超额=个股-上证指数。

## 结论摘要
- 样本很小: 强买 2、关注 27、冲突 10、弃 5,只能做机制诊断,不能做统计结论。
- 4 档标签整体方向正确: 强买 5 日前向 +5.7%、超额 +6.0%; 弃 3 日前向 -2.5%。
- 冲突档不应直接理解为利空: 命中量化但 LLM Underweight 的 10 条,5 日前向 +3.1%,反而强于关注档。
- 置信分有排序能力: 0-30 组 5 日 -4.5%; 31-60 组 +0.9%; 61-100 组 +4.2%。
- 最大问题不是方向,而是样本量和数据获取稳定性。

## 本轮已实施优化
1. **vendor 工具结果缓存**(180s): 7 个 Analyst 常重复请求同一 ticker/date,批量 9 只时同一接口可能被请求几十次;现在同参数只打一次。
2. **中文评级解析**: 历史 free-text 里大量 `最终评级：减持 (Underweight)` 之前被判 Unknown,现可正确归为 Underweight。
3. **数据源兜底**: insider / fund flow / industry / 财务报表均有第二数据源。
4. **报告加载容错**: 缺失字段不阻塞报告,显示为空/缺失说明。

## 待评估方向
- 强买样本只有 2,需继续积累 4 档标签样本后再做分档统计。
- 冲突档可考虑展示“量化看多但 LLM 谨慎”时给更多证据,而不是让用户误判为卖出。
- 引入按信号日期的滚动再评估,而不是只在发布前看一次。
